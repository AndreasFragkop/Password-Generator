# Password Generator

A simple, client-side password generator with configurable length and character sets.

## Features
- Custom length (4-50)
- Uppercase, lowercase, numbers, symbols toggles
- Passphrase mode (word list + separators)
- Strength indicator
- Copy to clipboard

## Run
Open `index.html` in your browser.

## Files
- `index.html`
- `style.css`
- `script.js`
